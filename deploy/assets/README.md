# deploy/assets

运营者放置的静态资产目录。

## wecom_kf_qr.png（客服入口二维码）

企微管理后台「应用管理 → 微信客服 → 客服账号详情」生成并下载。
`GET /kf` 公开落地页展示它，新用户扫码/长按识别即可进入小盾会话；
JPG/PNG 均可，扩展名与真实格式一致（或用 `WECOM_KF_QR_PATH` 指向其他路径）。

## wecom_plugin_qr.png

微信插件邀请二维码：企微管理后台「我的企业 → 微信插件」生成并下载，
放置为本文件名（或用 `WECOM_PLUGIN_QR_PATH` 指向其他路径）。

推送开通流程的第一屏会把它经客服会话下发给联防者，并在控制台兜底展示；
文件缺失时两者都会降级为纯文字指引（二维码是关注插件这一前提动作的唯一入口）。
