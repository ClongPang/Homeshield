# 函数命名规范与改名清单

## 规则

本项目的 Python 函数和方法遵循以下约定：

1. 使用 `snake_case`。
2. 优先采用“动作 + 对象”，如 `create_group`、`list_members`。
3. 名称体现返回范围：单个对象、列表、布尔判断要能区分。
4. 名称体现特殊行为，如选择上下文、验证权限、检查容量。
5. 同一类操作统一动词；`list_` 返回集合，`require_` 缺少前置条件时抛错，`create_` 创建对象，`find_` 可返回空值。

只重命名函数和所有仓库内调用点，不改函数体、参数、返回值、错误语义、数据库字段、HTTP 路径、命令文本或业务顺序。测试与调用点同步改名。已注册为 FastAPI 路由的处理函数固定原有 `operation_id` 和摘要，避免函数改名改变 OpenAPI。仓库外若直接导入这些 Python 函数，需要改用新名称；本轮不保留旧名称别名。

`_resolve_group_selector` 保留当前“群信息或错误文案”的返回形态；把它拆成不同返回类型属于行为/接口重构，不在本轮改名范围内。

- README 与当前说明文档中的函数引用已同步；历史报告继续使用稳定的输出字段名 `fpr_strict`。
